# Long-Term Memory

Store only concise, stable information that is useful across conversations and affects future collaboration:

- User background and long-term goals.
- Explicit communication, work, and decision preferences.
- Standing behavior boundaries and confirmation requirements.
- Long-term project purposes, key constraints, and reference locations.
- Verified, reusable experience.

This is not a chat log or a source of one-time authorization. Keep temporary states, one-off tasks, and useful but unconfirmed suggestions in dated notes only when they may affect future action; otherwise omit them.
